# 隐私说明

## 本地存储内容

本应用在设备本地存储以下数据：

- **主机配置**：名称、地址、端口、用户名、分组、跳板链、环境变量、初始命令、tmux 会话名。
- **凭据**：密码、私钥短语（经 DPAPI 加密后存储于 `secure/secrets.bin`）。
- **密钥**：导入的私钥与生成的密钥对（经 DPAPI 加密后存储）。
- **外观配置**：主题、字号、配色、光标样式等。
- **已知主机**：服务器公钥指纹（TOFU）。
- **设置**：主题、语言、字号、回滚行数、常亮策略、同步轮询间隔等。
- **日志**：运行日志（`LocalState/logs/app.log`），格式 `yyyy-MM-dd HH:mm:ss.fff [LEVEL] [Tag] message`。

所有本地数据均存储于应用的 `LocalFolder`，不会自动同步到任何外部服务器，除非用户主动启用云同步。

## 同步内容与加密方式

启用云同步后，以下内容会加密上传至同步服务器：

- 主机配置（不含密码/短语，除非开启「同步密码与短语」）
- 隧道、分组、片段配置
- 凭据（密码、短语，需开启「同步密码与短语」）
- 私钥（需开启「同步私钥」）

**加密方式**：

1. **同步密码**：用户设置的同步密码（≥8 位）经 Argon2id（RFC 9106 §5.3 参数）派生为 256 位密钥。
2. **密钥封装**：上述密钥用于 AES-256-GCM 加密同步文档。
3. **恢复密钥**：建库时生成的 SPM1 格式恢复密钥（SPM1-[A-Za-z0-9_-]{43}-[A-Fa-f0-9]{12}），可在同步密码遗忘时解锁保险库。
4. **传输**：加密后的文档经 HTTPS（或明文 HTTP，见下文风险）上传。

服务器仅存储密文，无法解密用户配置。

## 服务器地址与明文 HTTP 风险

- **同步服务器**：`123.161.179.32:46926`（由 `appconfig.json` 的 `syncApiBaseUrl` 配置，默认 `https://`）。
- **明文 HTTP 风险**：该服务器目前未启用 TLS，客户端在 https 失败时会自动降级为 `http://`（`httpFallback`），因此实际仍是明文。在不可信网络（公共 Wi-Fi、企业代理）下，登录密码与同步文档可能被同一网络内的攻击者窃听。应用会在登录页显示「当前为未加密连接」Banner 提醒用户。
- **建议**：仅在可信网络下使用；部署时建议改用 HTTPS。

## 日志不含敏感信息

所有日志在写入前经过脱敏处理（`LogRedactor`），以下内容不会出现在日志中：

- 密码、短语、令牌、恢复密钥
- `-----BEGIN ... -----END ...` 私钥块
- `SPM1-...` 恢复密钥
- `Bearer ...` 授权头
- 任何匹配 `password|passphrase|token|accessToken|refreshToken|privateKey|recoveryKey|ciphertext|authorization|syncPassword` 的 `key=value` 或 `"key":"value"` 形式

## 数据删除

- **删除主机**：级联删除其隧道与 `jumpHostId` 引用，凭据同步删除。
- **删除分组**：清除主机与隧道的 `groupId` 引用。
- **删除密钥**：被主机引用时拒绝删除。
- **清空日志**：设置页「清空日志」删除全部本地日志文件。
- **注销账号**：永久删除云端保险库与账号（需登录密码 + 输入 `DELETE` 确认）。
- **删除云端保险库**：仅删除云端数据，本机配置保留。

## 第三方服务

本应用不使用任何第三方分析、广告或追踪服务。唯一外部通信为同步服务器（用户可选启用）。
