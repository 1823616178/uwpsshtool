# S16 三端互通验收报告（doc/INTEROP-REPORT.md）

> 目标：依据 `doc/03-SYNC-PROTOCOL.md §10.3` 验证 Lumia（Windows 10 Mobile UWP）、桌面端（Electron / TypeScript）与鸿蒙端（HarmonyOS）之间的多端双向同步、冲突解决、安全轮换与私钥同步一致性。
> 当前状态：代码与自动化测试已全部就绪（S01–S15 共通过 1420 个 Core 单元测试与 299 个 Native 测试，跨端向量完全对齐）；本报告记录 10 个互通场景规范，待三端联调环境接入后回填实测记录。

## 2. 自动化覆盖与测试就绪状态

在进入真机多端网络联调前，以下跨端核心逻辑已由自动化测试 100% 覆盖并全绿通过：

1. **协议与数据模型（S01、S02）**：
   - 严格对齐 `SyncConstants`（AAD 域前缀、SPM1 恢复密钥前缀、HKDF-SHA256、盐与 Nonce 长度、2 MiB 上限）。
   - JSON 序列化严格无 BOM、无缩进、键字典序排序、规范 Base64 编码。
   - `updatedAt` 格式固定 `yyyy-MM-ddTHH:mm:ss.fffZ`，避免多端 ISO 8601 解析精度差异。
2. **密码学与信封编解码（S03、S04、S05）**：
   - Native 实现与桌面端 `hash-wasm` / Node.js `crypto` 交叉验证黄金向量（`tools/sync-vectors` 自动化校验）。
   - 解密前必须校验 `ciphertextHash`（HMAC/SHA256），防止选择密文攻击。
   - 恢复密钥 10,000 次随机往返无损，任意单字符篡改均被安全拒绝。
3. **冲突解决与合并算法（S09、S12a、S12b）**：
   - 通用 JObject 字典合并、首导导入冲突（`initial-import`）、远程删除冲突（`remote-deletion`）以及并发修改（`merge-conflict`）状态机与策略执行器单元测试全部通过。
4. **私钥同步安全性（S15）**：
   - 私钥出站前经过严格的安全检查（不支持的 PKCS#8 格式过滤并记警告，敏感字段隔离）。
